**State:**

- `const wrapRef = useRef<HTMLDivElement>(null);`

**GSAP ScrollTrigger setup (in useEffect, deps=[]):**
```
// 1. Per-step triggers: set active index when step center crosses viewport center
stepEls.forEach((stepEl, i) => {
  ScrollTrigger.create({
    trigger: stepEl,
    start: 'center center',
    end: 'center center',
    onEnter: () => setActive(i),
    onEnterBack: () => setActive(i),
  });
});

// 2. Rail fill progress: scrub a value from 0→100 as section scrolls
ScrollTrigger.create({
  trigger: wrapRef.current,
  start: 'top center',
  end: 'bottom center',
  scrub: 1,
  onUpdate: (self) => setRailFill(self.progress * 100),
});
```

**JSX structure (from services-app.jsx SMethod layout):**
```tsx
<section className="sec border-t">

      <p className="sec-intro">{ts.intro}</p>
    </div>

    <div className="method" ref={wrapRef}>
      <div className="method-rail" />
      <div className="method-rail-active" style={{ height: `${railFill}%` }} />

        {ts.steps.map((s, i) => (
```
