## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| storage bytes -> sealer | original object re-hashed before use |
| sealer -> storage/DB | non-transactional pair handled by A/B/C |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-33 | Tampering | corrupted or swapped original | mitigate | sha256 of downloaded bytes compared to the issued row before sealing |
| T-14-34 | Repudiation | fact posted without seal | mitigate | fact only inside sv_seal_document; upload failure never calls the RPC; tests assert it |
| T-14-35 | Tampering | overwrite of a seal | mitigate | upsert:false, random UUID path, unique storage_path and unique document_id in SQL |
| T-14-36 | Denial of service | oversized output | mitigate | size checked against the 10 MB bucket limit before upload |
| T-14-37 | Information disclosure | certificate content | accept | IP and e-mail printed by design (D-08); RGPD retention listed for legal review (Deferred) |
</threat_model>
