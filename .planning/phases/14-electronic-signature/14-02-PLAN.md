  <behavior>
    canonicalJson:
    - {b:1,a:{d:2,c:[3,{f:1,e:2}]}} -> '{"a":{"c":[3,{"e":2,"f":1}],"d":2},"b":1}' (sorted keys at every depth, no whitespace)
    - strings use JSON.stringify escaping (control char U+001F becomes "\u001f", so the separator can never appear raw)
    - undefined values, functions, NaN, Infinity throw; null kept; nested arrays keep order
    genesisHash / linkHash:
    - genesisHash('00000000-0000-0000-0000-000000000001') equals the sha256 hex of 'sv-genesis:00000000-0000-0000-0000-000000000001' computed independently in the test with node:crypto
    - linkHash with actorId null and ip null uses empty strings in those positions (test builds the joined string by hand)
    verifyChainExport(input: unknown):
    - a valid 3-event export built in the test (each linkHash computed by the test helper) -> { ok: true, count: 3, headHash: last linkHash }
    - empty events with headHash null -> { ok: true, count: 0, headHash: null }
    - first event prevHash !== genesisHash -> { ok: false, brokenAtSeq: 1, reason: 'prev_hash' }
    - payload of event 2 altered -> { ok: false, brokenAtSeq: 2, reason: 'link_hash' }
    - event 2 removed (seq gap) -> { ok: false, brokenAtSeq: 3, reason: 'seq' }
    - headHash differs from last linkHash -> { ok: false, brokenAtSeq: null, reason: 'head' }
    - malformed input (missing fields, wrong formatVersion, non-hex hash, unknown eventType) -> { ok: false, brokenAtSeq: null, reason: 'format' }
    - events.docSha256 / templateVersion are hashed per event (altering them breaks the link)
  </behavior>
