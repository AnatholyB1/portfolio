## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-14-46 | Spoofing | actor or e-mail forged by the client | mitigate | actor id = ctx.user.id, e-mail = ctx.user.email; no form field accepted |
| T-14-47 | Elevation of privilege | IDOR on another client's document | mitigate | RLS read first in loadSigningContext, createPreviewUrl and the apercu route; SQL re-checks membership |
| T-14-48 | Tampering | malformed answers or code | mitigate | zod validation, UUID regex, SQL re-validation |
| T-14-49 | Repudiation | consent skipped | mitigate | sendCodeAction refuses unchecked flags; SQL refuses a code without consent |
| T-14-50 | Denial of service | code spamming | mitigate | SQL 60 s / 5 per hour per document; UI cooldown is cosmetic only |
| T-14-50b | Elevation of privilege | code sent or verified before the project step allows signing (stale page) | mitigate | sendCodeAction/verifyCodeAction re-run checkSignable via loadSigningContext before any RPC; unit-tested for wrong_step |
| T-14-50c | Tampering / Information disclosure | apercu handler (conditional) serving altered bytes or caching the PDF | mitigate | sha256 compare -> 409; Cache-Control private, no-store; X-Frame-Options SAMEORIGIN |
