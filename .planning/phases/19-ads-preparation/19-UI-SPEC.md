# Phase 19 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Mode: non-interactive auto. Decisions come from 19-CONTEXT.md (D-01..D-13) and 19-RESEARCH.md. Everything else reuses the back-office `pt-*` design system and is marked (default) when chosen here.

Surfaces covered (all back-office, French, `noindex`, behind `requireAdmin()`; no public-site UI):
1. `/admin/liens` : UTM link generator (new AdminNav entry)
2. "Hors convention" indicator in the funnel (`/admin/entonnoir`)
3. "Hors convention" indicator in the leads list (`/admin/leads`) and the lead detail (`/admin/leads/[id]`, Attribution card)
4. Read-only "Conversions" card in the lead detail (journal display, "valeur manquante" case)

## Color

Existing palette only (PRODUCT.md constraint); no new hex.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--bg` #0A0B0C | Page background |
| Secondary (30%) | `--bg-2` #111213 (borders `--line` #1F1F1F, strong borders `--pt-border-strong` #6f6b64) | `pt-card`, table, result block, inputs |
| Accent (10%) | `--acid` #C4F542 | See reserved list below |
| Destructive | `--warm` #E07856 | Not used for destructive actions in this phase (none exist). Used only for validation error text via `pt-error` |

Text: `--ink` #ECEAE3 primary, `--ink-dim` #9A9690 secondary. Never `--ink-faint` for meaningful text.

Accent reserved for:
1. Primary button "Copier le lien" (`pt-btn-primary`), the single primary action of `/admin/liens`
2. Focus ring on every interactive element (2px `--acid`, offset 2px, as `leads.css`)
3. The AdminNav active item (existing `pt-admin-nav-active`)
4. The status icon of a conformant link ("Conforme à la convention", CheckCircle2 16px)

"Hors convention" is a warning, not an error: it is a neutral badge (`pt-lead-badge`, `--ink` text, `--pt-border-strong` outline) with a lucide `TriangleAlert` 16px icon in `--ink`, plus the text. It is never accent-filled and never `--warm` (the lead is valid; only its tagging needs correction). State is always conveyed by icon + text, not by color. Reason text inside the lead detail uses `pt-warn` only if that class already has AA contrast on `--bg-2`; otherwise `--ink`.

## Layout and Components

### 1. AdminNav entry
- Add `'liens'` to `AdminNavItem`; item `{ key: 'liens', href: '/admin/liens', label: 'Liens' }` inserted after `Entonnoir` (before `Pilotage`), since it is the campaign tooling that feeds the funnel. (default)
- No other nav change. `AdminNav` test key list is updated accordingly.

### 2. `/admin/liens` (link generator)
- Shell identical to `/admin/avis`: `ShellHeader variant="admin"`, `ShellMain width="admin"`, `.pt-admin` flex column gap 32px, `<AdminNav current="liens" />`, `export const dynamic = 'force-dynamic'`, `metadata = { title: 'Liens de campagne', robots: noindex }`.
- Section A, `pt-card` "Générer un lien" (h1 `Liens de campagne` above as page title inside the first card, as `/admin/avis`). Intro `pt-helper`: "Composez l'adresse à utiliser dans vos annonces et sur la fiche Google Business. Le lien produit respecte toujours la convention de nommage."
- Form is a client component `LinkBuilder` that computes the result live from the pure rules module (no server round-trip, no submit button). Fields, single column then 2-column grid as per Spacing:
  1. **Plateforme** (required, `<select>`): "Meta Ads" (`meta` / `paid_social`), "Google Ads" (`google` / `cpc`), "Fiche Google Business" (`gbp` / `organic`). Default "Meta Ads". Changing it sets Support to the preset medium.
  2. **Support** (required, `<select>`): the four allowed mediums (`paid_social`, `cpc`, `organic`, `referral`) shown with their value in mono next to a French label ("Réseaux sociaux payants", "Recherche payante", "Organique", "Site référent"). Preselected by Plateforme; editable. Helper: "Valeur proposée selon la plateforme."
  3. **Page de destination** (required, `<select>` of site paths, never free URL to prevent open redirect): `/` Accueil, `/simulateur`, `/contact`, `/realisations`, other public indexable routes from the site map. Default `/`. The origin is fixed to `NEXT_PUBLIC_SITE_URL` and shown as a read-only prefix.
  4. **Offre** (required, text): helper "Ex. agent-vocal". Slugified live (minuscules, sans accents, tirets).
  5. **Cible** (required, text): helper "Ex. restaurants".
  6. **Mois** (required, `<input type="month">`, default current month): rendered into `aaaamm`.
  7. **Variante de création** (optional, text, `utm_content`): helper "Ex. video-a, carrousel-1".
  8. **Mot-clé** (optional, `utm_term`): shown only when Plateforme = Google Ads; hidden otherwise (not just disabled).
- Live slug rule: all free text passes through the module's slugifier; a line under the field shows the normalised value in mono ("Sera écrit : agent-vocal") only when it differs from what was typed.
- Result block (`pt-card` inner, `aria-live="polite"` region, always visible once required fields are filled):
  - Label "Lien à utiliser" + read-only `<textarea readonly rows=3>` or `<output>` in mono showing the full URL (never truncated; wraps).
  - Below, the decomposed values as a `pt-summary` dl: Source, Support, Campagne (`offre_cible_aaaamm`), Contenu, Terme.
  - Validation line: conformant -> CheckCircle2 + "Conforme à la convention" (Label, accent icon). Not conformant (e.g. campaign over 60 characters, empty required block) -> `TriangleAlert` + the specific reason in French, and the "Copier le lien" button is `disabled` with `aria-disabled`. The builder cannot emit a non-conformant URL.
  - Actions row: "Copier le lien" (`pt-btn-primary`, 44px) and "Ouvrir le lien" (`pt-btn-ghost`, `target="_blank" rel="noopener noreferrer"`, sr-only suffix " (s'ouvre dans un nouvel onglet)"). Copy feedback in a `pt-status` live region: "Lien copié".
  - Character counter on Campagne: "{n} / 60 caractères" (Label, `--ink-dim`; updates announced only when crossing 60).
- Section B, `pt-card` "Convention" (static, server-rendered from the rules module, so docs and UI cannot drift):
  - Table (`pt-admin-table`, `<caption>` sr-only) of Sources autorisées (`meta`, `google`, `gbp`) with plateforme and typical support; table of Supports autorisés; format campagne `offre_cible_aaaamm` with example `agent-vocal_restaurants_202611`; alias list as a compact two-column table "Valeur reçue -> valeur enregistrée" (e.g. `facebook`, `fb`, `instagram`, `ig` -> `meta`).
  - Closing helper: "Un lien hors convention est conservé et signalé « Hors convention » dans l'entonnoir et sur la fiche du lead." plus a link text "Document de convention" pointing to `docs/convention-utm.md` rendered as plain mono path (no external hosting, not a link).
- Google Business preset: a quick-action ghost button "Préremplir pour la fiche Google" sets Plateforme = Fiche Google Business, Page = `/`, Offre = `fiche-google`, Cible = `local`, Mois = current. (default)
- States: initial (required fields empty -> result block shows placeholder helper "Remplissez l'offre et la cible pour générer le lien."), valid, invalid (per above), clipboard unavailable (fallback: select the text, status "Copiez le lien manuellement (Ctrl+C)").

### 3. Funnel indicator (`/admin/entonnoir`)
- In `FunnelTable`, the Source cell (`<th scope="row">`) appends, when `nonconformingLeads > 0` for that row, a `pt-lead-badge` after the source text (gap 4px): icon `TriangleAlert` 16px + "Hors convention" + count in parentheses "(3)". Row `title` / sr-only text: "{n} lead(s) de cette ligne ont une source hors convention".
- Above the table, only when the total over the selected period is > 0: one `pt-helper` line "{n} lead(s) hors convention sur la période. Ouvrez la fiche du lead pour corriger la source." No new column in the visible table (keeps the 9 existing columns and the total row unchanged). (default; avoids widening a table that already scrolls horizontally)
- No indicator when 0; no "Conforme" badge anywhere (absence is the normal state).

### 4. Leads list (`/admin/leads`)
- In `LeadsTable`, the source cell shows the same `pt-lead-badge` "Hors convention" (without count) after the source text when the lead is flagged. Leads created before this phase (columns null) show nothing.

### 5. Lead detail, Attribution card
- When the lead is flagged, insert at the top of the `AttributionCard` (above "Premier contact") a notice block (`role="note"`, bordered with `--pt-border-strong`, 16px padding, 8px inner gap):
  - Line 1 (Label): `TriangleAlert` + "Hors convention".
  - Reasons as a `<ul>`, each reason in French (map below), Body 16px.
  - Helper: "Les valeurs ont été conservées telles quelles. Corrigez la source ci-dessous si elle est erronée." The existing `CorrectSourceForm` is the correction mechanism; the notice does not duplicate it. Correcting clears the flag; the raw values remain visible in the history.
- Raw vs canonical: when an alias changed a value (`source_raw` present), the affected `dd` in `Touch` shows the canonical value followed by a secondary line "Reçu : {raw}" (Label, `--ink-dim`, mono). No notice is shown for alias-only normalisation (the lead is conformant).
- Reason copy (closed list, matches `NonConformity`):

| Code | Display text |
|------|--------------|
| `source_missing` | Source (utm_source) absente alors que d'autres paramètres UTM sont présents. |
| `source_unknown` | Source inconnue : valeurs attendues meta, google ou gbp. |
| `medium_missing` | Support (utm_medium) absent alors que d'autres paramètres UTM sont présents. |
| `medium_unknown` | Support inconnu : valeurs attendues paid_social, cpc, organic ou referral. |
| `campaign_malformed` | Campagne mal formée : format attendu offre_cible_aaaamm (60 caractères maximum). |
| `content_malformed` | Variante de création mal formée : minuscules, chiffres et tirets uniquement. |

### 6. Lead detail, "Conversions" card (read-only)
- New `pt-card` after the Attribution card, h2 `pt-heading` "Conversions". Intro `pt-helper`: "Journal serveur des conversions. Aucun envoi aux plateformes publicitaires pour l'instant."
- Four rows in fixed order (Lead, Qualifié, RDV, Signé) as `pt-summary` dl: `dt` = rank label, `dd` = date (`formatDateFr`) + `event_id` in mono (`pt-lead-trunc`, `title` = full id) or `EM_DASH` + "Non atteint" in `--ink-dim` if the rank was not emitted. Signé `dd` appends the value: formatted EUR from `value_cents` via the admin euro formatter; if the row exists with null value: text "Valeur manquante" (Label, `--ink-dim`) with helper "Aucun devis actif au moment du passage à Signé."
- Tracking events (`quote_sent`, `lead_lost`) listed under the four ranks with subhead `pt-lead-subhead` "Suivi" only if present.
- Prices stay inside `src/components/admin` and `src/lib/server` (price scope respected); `src/lib/ads` stays price-free.

## Interaction and Accessibility (WCAG AA)

- Every field has a visible `<label for>`; helper linked via `aria-describedby`; required marked with text "(obligatoire)" in the label, not only an asterisk.
- Result block is an `aria-live="polite"` region updated on input with debounce 300ms; validation messages are not announced per keystroke.
- Keyboard: natural tab order = visual order; "Copier le lien" reachable immediately after the last field; Enter in a text field does not submit anything (no `<form>` submit; use `onSubmit` preventDefault).
- Badge: icon `aria-hidden="true"` + visible text; contrast of `--ink` / `--ink-dim` on `--bg` and `--bg-2` meets AA; border `--pt-border-strong` meets 3:1 for non-text UI.
- Focus ring: 2px `--acid` offset 2px on all new controls (extend the existing focus selector list with the `pt-link-*` controls).
- No animation; only 150ms color/border transition, disabled under `prefers-reduced-motion`. No cinema/cursor/GSAP.
- Responsive: 320px without horizontal scroll (URL wraps, tables inside a `tabIndex=0` scroll region like `pt-funnel-scroll`).
- All user-controlled strings (utm values, raw values) rendered as React text only; no `dangerouslySetInnerHTML`.
