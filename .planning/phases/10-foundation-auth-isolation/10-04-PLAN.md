<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous browser → requestLoginCode | untrusted email input, enumeration and mail-bombing attempts |
| server → Supabase Auth admin API | service_role privileged calls |
| server → Resend → recipient inbox | code and token travel by email |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-14 | Information disclosure | requestLoginCode | mitigate | identical result for invited/unknown/disabled; issuance deferred via `schedule` (after()) so timing is constant (D-09) |
| T-10-15 | Spoofing / Elevation | issueLoginCode | mitigate | sv_login_allowed gate before generateLink (magiclink would create users, Pitfall 2); no signInWithOtp/signUp anywhere (static test) |
| T-10-16 | Denial of service | code requests / verifications | mitigate | DB throttle per email hash and IP hash, fail-closed; Supabase verifyOtp limits remain |
| T-10-17 | Tampering | login email HTML | mitigate | escapeHtml on every interpolated value; tested with script payload |
| T-10-18 | Information disclosure | logs | mitigate | logs carry tag only; never code, token, email or raw IP |
| T-10-19 | Spoofing | mail to non-invited Ziko/Gecko users | mitigate | gate happens before any send; SV_LOGIN_ENABLED off until D-20 evidence |
</threat_model>
