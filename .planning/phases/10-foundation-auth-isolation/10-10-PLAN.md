<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| anonymous browser → Server Actions | untrusted email, code, token_hash, next |
| mail scanners → /auth/confirm | automated GETs on emailed links |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-40 | Information disclosure | requestCodeAction | mitigate | identical state for all addresses; issuance via after() (D-09) |
| T-10-41 | Spoofing | verifyCodeAction (brute force) | mitigate | checkVerifyThrottle per email/IP + Supabase verifyOtp limits; zod 6-digit format |
| T-10-42 | Denial of service | fallback link burned by scanners | mitigate | GET renders a button only; POST action verifies (D-10) |
| T-10-43 | Tampering | `next` open redirect | mitigate | safeNext by role destination |
| T-10-44 | Elevation of privilege | verified user without role | mitigate | getRoleDestination null → signOut + generic error |
| T-10-45 | Information disclosure | logs | mitigate | no code/token/IP in logs or returned state |
</threat_model>
