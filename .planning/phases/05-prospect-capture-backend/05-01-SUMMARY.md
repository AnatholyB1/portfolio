## Decisions Made
- **vitest version pin (4.1.11, not latest 5.0.1):** `npm install -D vitest` resolved to `vitest@5.0.1` by default, which requires `@types/node@^22.0.0 || >=24.0.0` — this repo has `@types/node@^20` as an existing devDependency, and Task 2 explicitly forbade modifying existing dependency versions. The vitest team publishes a dedicated `V4` dist-tag (`4.1.11`) that remains compatible with `@types/node@^20`, so it was installed via `npm install -D vitest@4.1.11` instead of bare `vitest`. This is still the exact `vitest` package approved in Task 1 — only the major version differs from npm's `latest` tag.
- **`passWithNoTests: true`:** Vitest 4.x exits 1 by default when no test files match the include glob. Task 2's acceptance criteria required `npx vitest run` to exit 0 with no test files present (before Task 3 adds the first one), so this option was added to satisfy that contract.
