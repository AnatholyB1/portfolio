- Return 50 when the count is 0.
- Otherwise return `Math.max(0, Math.min(100, 100 - Math.round(total / count)))`.
- Add an inline comment stating the inversion is D-11: severity measures unmet need, the displayed value measures maturity, so a struggling business sees a LOW number and the result copy frames that as opportunity rather than as a compliment.
