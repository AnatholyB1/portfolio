## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| visitor input → component state → `POST /api/simulateur` | Free-text `nom` / `email` / `telephone` enter here. They are never rendered as HTML by this component and are re-validated plus `escapeHtml`d server-side before reaching Supabase or the Resend template. |
| bot → contact form | Automated submissions are filtered server-side by `isSpamSubmission`; this component's only obligation is faithfully emitting the two fields that check reads. |
