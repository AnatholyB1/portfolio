## Trust Boundaries

|----------|-------------|
| Internet -> /api/stripe/webhook | public, unauthenticated; trust only after signature verification |
| client portal -> createCheckoutForInvoice | authenticated client chooses an invoice id only |
| server -> Stripe API | secret keys, money movement |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-29 | Spoofing | webhook | mitigate | raw-body SDK verification, 400 on failure, livemode check, no state change before verification |
| T-15-30 | Tampering | amount | mitigate | unit_amount from DB invoice minus credits; RPC re-checks amount due; webhook compares paid amount |
| T-15-31 | Elevation | IDOR on pay | mitigate | invoice read through the caller's RLS client before any service_role step |
| T-15-32 | Elevation | refund abuse | mitigate | refund only from an issued credit note with refund_requested, amount from DB, idempotency key per credit note, admin-only caller (15-16) |
| T-15-33 | Tampering | open redirect | mitigate | success/cancel URLs from getSiteUrl and fixed paths; invoice id is a DB uuid |
| T-15-34 | Denial of service | webhook retries | accept | Stripe retries on 500; replay is a no-op through sv_stripe_events |
| T-15-35 | Information disclosure | logs and responses | mitigate | fixed-string logs and response bodies, no ids or payloads |
