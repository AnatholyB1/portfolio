## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webhook route (service_role) -> sv_apply_stripe_event | verified event fields enter the ledger |
| client portal -> ledger | RLS read of own invoices' payment state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-13 | Tampering | duplicate or replayed events | mitigate | sv_stripe_events PK, processed_at set last in the same transaction, ledger unique stripe_event_id |
| T-15-14 | Tampering | amount or currency differing from invoice | mitigate | compare with amount due and 'eur'; mismatch = anomaly, no fact, no receipt |
| T-15-15 | Spoofing | live/test confusion on an invoice | mitigate | livemode must match a recorded checkout session of the invoice |
| T-15-16 | Information disclosure | Stripe ids and URLs | mitigate | sv_stripe_events no authenticated grant; sessions and customers admin-only; client column grant limited to kind, amount, method, date |
| T-15-17 | Elevation | double payment via second session | mitigate | session refused while the invoice or another invoice of the client is processing |
| T-15-18 | Repudiation | event history tampering | mitigate | append-only ledger; only processed_at null-to-value update allowed by trigger |
</threat_model>
