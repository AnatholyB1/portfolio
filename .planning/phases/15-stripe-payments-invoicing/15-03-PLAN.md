## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server (service_role) -> invoice RPCs | only path that writes invoice rows |
| authenticated client -> invoice tables | RLS read of own project invoices |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-15-07 | Tampering | invoice rows and numbers | mitigate | deny_mutation triggers incl. service_role, no insert grant, unique (series, year, seq), counter monotonic trigger |
| T-15-08 | Tampering | gaps from rollback or race | mitigate | counter row upsert in the same transaction as the insert; no SEQUENCE |
| T-15-09 | Information disclosure | client reads of other clients' invoices | mitigate | RLS policy is_admin or project_ids(); column grants exclude snapshot, created_by, storage_path |
| T-15-10 | Elevation | forged amounts via RPC args | mitigate | RPC re-verifies line formula and sums; RPC executable only by service_role |
| T-15-11 | Repudiation | erasure of invoices | mitigate | on delete restrict on every FK; immutable rows (10-year retention) |
| T-15-12 | Tampering | test client consuming legal series | mitigate | is_test drives TFA/TAV; flag locked once the client has invoices |
</threat_model>
