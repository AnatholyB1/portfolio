## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-23 | Spoofing | forged webhook | mitigate | signature verified on the raw body with the SDK; 400 otherwise; fail-closed 500 without secret |
| T-16-24 | Tampering | webhook replay / Svix retry | mitigate | svix-id as primary key in sv_resend_events; duplicate returns early; SDK timestamp tolerance |
| T-16-25 | Tampering | link scanner unsubscribes the recipient | mitigate | GET answers 405 and never writes; only POST records |
| T-16-26 | Tampering | unsubscribe of a third party | mitigate | HMAC token required; no endpoint accepts a bare address |
| T-16-27 | Information disclosure | address enumeration | mitigate | identical response for 'recorded' and 'already'; generic 400 for invalid tokens |
| T-16-28 | Information disclosure | token leaks via logs/referrer/cache | mitigate | fixed-string logs, Referrer-Policy no-referrer, Cache-Control no-store, redirect never echoes t |
| T-16-29 | Denial of service | oversized input | mitigate | token length <= 600; webhook to[] bounded in toApplyArgs and in the RPC |
