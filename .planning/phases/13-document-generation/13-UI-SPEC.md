# Phase 13 — UI Design Contract

> Visual and interaction contract for phase 13. Generated by gsd-ui-researcher (auto chain, no questions asked), verified by gsd-ui-checker.
> Three surfaces: (A) portal Documents tab, (B) admin project sheet "Documents" section, (C) PDF layout of the 5 templates.
> Sources: 13-CONTEXT.md (D-01..D-17), 13-RESEARCH.md (stack, spike findings), existing `portal.css`, `project.css`, `projects.css`, `globals.css`, `FilesPanel.tsx`, `ClientNav.tsx`, `copy.ts` (`PROJECT_COPY`). Surfaces A and B reuse the existing private-space design system unchanged (no new tokens). Surface C is a separate print contract (light paper, not the dark UI).

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (no `components.json`; custom `pt-*` CSS in `src/app/portal.css`, `project.css`, `projects.css`, no Tailwind utilities in private spaces). shadcn gate: project is not shadcn-based and phases 10-12 locked a custom scoped system; not initialized, not proposed. |
| Preset | not applicable |
| Component library | none (native elements + `pt-*` classes) |
| Icon library | `lucide-react` (already used: `Download`, `FileText`, `Upload`), 16px, `aria-hidden="true"` |
| Font (portal/admin) | Body Manrope (`var(--font-body)`), headings Space Grotesk (`var(--font-display)`), mono JetBrains Mono (`var(--font-mono)`) for hashes, references, versions |
| Font (PDF) | Manrope Latin 400 + 700, WOFF embedded as base64 data URI (`fontData.ts`), registered once by `setupPdf()`, hyphenation disabled |

Scoping: portal tab styles go in `src/components/portal/project/project.css` under `.pt-root`; admin styles in `src/components/admin/projects/projects.css` under `.pt-admin`. New class prefix `pt-doc-*`. No animation (back-office sobriety, D-17); color/border transitions 150-200ms only, already disabled by `prefers-reduced-motion` globally. No cinema, no custom cursor, no GSAP. French only, `noindex` inherited from the shells.

## Typography

Web (surfaces A and B): 3 sizes used (14, 16, 24), 2 weights (400 regular, 500 medium, the weights already used by `.pt-root`). 32px `pt-display` is not used in this phase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (cell text, form values, helper, paragraphs) | 16px | 400 | 1.5 |
| Label / meta (column headers, field labels, dates, badges, hash, version, "Remplacé par…") | 14px | 500 (badge, label), 400 (meta) | 1.5 |
| Heading (page title "Documents", section "Documents du projet", panel titles) | 24px | 500 (Space Grotesk, letter-spacing -0.02em) | 1.2 |
| Display | not used | — | — |

Monospace (JetBrains Mono, 14px, 400) is a font-family variation, not a size/weight: SHA-256 (shown as 64 hex characters, `word-break: break-all`, with a "Copier" text button), template version (`v1`), document reference.

Numbers: amounts and quantities in tables use `font-variant-numeric: tabular-nums`, right-aligned. Amount format everywhere (admin form summary, PDF): `1 234,50 €` with U+00A0 as thousand and before-currency separator, produced by `formatEuros(cents)` (never `Intl` fr-FR, U+202F bug). Dates: `formatDateFr` (Europe/Paris, `12 octobre 2026`).

## Surface A — Portal Documents tab (`/espace-client/documents`)

DOC-03, D-14, D-15. Server component, RLS client, no prices anywhere (the `portalPage.test.ts` "no price token" test applies; update its `Documents (bientôt)` assertion deliberately).

**Navigation.** `ClientNav` gains a second real link: `Projet` (`/espace-client`) and `Documents` (`/espace-client/documents`), both `Link`; `aria-current="page"` on the active one with `.pt-client-nav-active`. `Paiements (bientôt)` stays disabled.

**Layout** (inside `ShellMain`, same width as the project page):
1. `h1.pt-heading` "Documents".
2. If several projects: the existing `ProjectSelector`; documents grouped per project, each group has `h2` (project title, 24px/500) when there is more than one project, no `h2` when only one.
3. Document table, `.pt-table`, `<caption class="pt-sr-only">Documents du projet {title}</caption>`:

| Column | Content |
|--------|---------|
| Document | Icon `FileText` 16px + type label (Devis, Contrat, Cahier des charges, PV de recette, Facture) |
| Émis le | `formatDateFr(issued_at)` |
| Version | `Version {revision}` (14px/400, `--ink-dim`), e.g. "Version 2" |
| Statut | status badge |
| Action | `.pt-btn-text` "Télécharger" with `Download` 16px; label becomes "Préparation…" and the button is `disabled` while the signed link is generated |

Order: by type in the project flow order (Devis, Cahier des charges, Contrat, PV de recette, Facture), then newest revision first within a type. Active document first; replaced revisions follow directly below their type, "en retrait".

**Replaced rows ("en retrait").** Same row, `.pt-doc-replaced`: text `--ink-dim`, 2px left border `--line-strong`, first-cell indent 16px (`padding-left`), badge "Remplacé", plus meta line under the type label: "Remplacé par la version {n+1} du {date}" (14px/400). Download remains available (the client can always retrieve what they received).

**Mobile (<640px).** Existing `.pt-table` stacked mode with `data-label` attributes (same as `FilesPanel`): each row becomes a card, labels shown, Action cell full width with 44px target.

**States.**
- Loading: server rendered, no skeleton.
- Empty (no document for any project): `.pt-card` with `h2` "Aucun document pour le moment" and `.pt-helper` "Votre devis, votre contrat et vos autres documents apparaîtront ici dès qu'ils seront émis. Vous recevrez un e-mail à chaque nouveau document."
- Download error: `.pt-error` under the table in an `aria-live="polite"` region: "Le téléchargement n'a pas pu démarrer. Réessayez dans un instant ; si le problème continue, écrivez-nous."
- Download success: browser navigation to the signed URL (`window.location.assign`), no toast. Link lives ~120 s, never rendered into the DOM as a visible/stored href.

**No** PDF viewer, no preview, no amounts, no SHA-256, no template version shown to the client.

## Surface B — Admin project sheet, section "Documents" (`/admin/projets/[id]`)

D-01, D-02, D-03, D-05, D-06..D-09, D-16. A new section in the existing sheet, placed after the Files panel, `h2.pt-heading` "Documents" inside a `.pt-card`. Components: `DocumentsPanel` (orchestrator), one form component per type, `DocumentPreview`, `IssuedDocumentsList`, `SnapshotPanel`. Client components only for forms and preview; reads are server-rendered. Prices are allowed here.

### B1. Expected documents at the current step

A block `.pt-doc-expected` (`--bg-3`, 1px `--pt-border-strong`, 8px radius, 16px padding) per document expected at the current step (D-05: step 2 Devis + Cahier des charges, 3 Contrat, 5 PV de recette, 6 Facture). Content:
- Type label (16px/500) and one-line status in 14px `--ink-dim`: "À émettre", or "Émis, version {n}" when an active one exists (button then reads "Remplacer", see B5).
- Prerequisite line when blocked: Contrat needs an active Devis, PV needs an active Cahier des charges. Text: "Émettez d'abord le devis." / "Émettez d'abord le cahier des charges." The button is `disabled` and `aria-describedby` points to this line.
- Primary entry: `.pt-btn-ghost` "Générer" (replaced by "Remplacer" when an active document exists) opens the type form inline below the block (no modal, no route). Only one form open at a time.
- No document expected at this step (e.g. step 1, 4, 7): `.pt-helper` "Aucun document attendu à cette étape." and the issued list still shows.
- Facture at step 6: block labelled "Facture (aperçu uniquement)" with helper "L'émission des factures arrive avec le module de paiement. L'aperçu porte la mention PROFORMA et n'est pas conservé." Only "Aperçu" is offered, never "Émettre".

### B2. Forms (zod, server-validated; client validation is display only)

All fields: `.pt-label` above, input 44px min-height, border `--pt-border-strong`, errors `.pt-error` below the field, linked by `aria-describedby`, `aria-invalid`. Required fields marked in the label text ("obligatoire" is implied; optional fields say "(facultatif)").

**Devis (D-06).**
- Repeating line group (`fieldset` per line, `legend.pt-sr-only` "Ligne {n}"): Désignation (text, max 200), Quantité (integer, min 1), Prix unitaire HT (€, decimal with comma, converted to cents), computed Montant HT (read-only, tabular-nums). Grid: designation 1fr, quantity 96px, price 144px, amount 144px, remove button 44x44.
- "Ajouter une ligne" `.pt-btn-ghost` (max 30 lines, then disabled with helper "30 lignes maximum"). Remove line: `.pt-btn-text` icon `X`... label `aria-label="Supprimer la ligne {n}"`; this edits an unsaved form only (not a destructive stored action), no confirmation. At least one line.
- Fields: Acompte (% entier 0-100, default 30), Validité de l'offre (jours, default 30), Délai de réalisation (texte, max 120).
- Totals recap `.pt-doc-totals` (right-aligned, 16px): "Total HT {x} €", "Acompte ({p} %) {y} €", "Solde {z} €", and the line "TVA non applicable, art. 293 B du CGI. Total TTC = total HT." Server recomputes; the preview shows the authoritative result.

**Cahier des charges (D-08).** Six `textarea` blocks, each with label, min 4 rows, max 4000 chars with live counter in 14px `--ink-dim` ("{n} / 4000"): Contexte et objectif (pre-filled from `project_goal`, helper "Prérempli depuis le questionnaire du client"), Périmètre, Livrables, Hors périmètre, Planning, Critères d'acceptation (helper "Un critère par ligne. Ils seront repris tels quels dans le PV de recette.").

**Contrat (D-07).** No editable clauses. Read-only recap card (`--bg-3`): parties, offre, montants du devis actif, acompte, dates (all from snapshots). Helper: "Les clauses sont fixes. Les montants viennent du devis émis." Only buttons "Aperçu" and "Émettre". Optional field: Date de début (date).

**PV de recette (D-09).** Read-only list of acceptance criteria taken from the active Cahier des charges (numbered, 16px). Fields: Date de livraison (date, required), Réserves éventuelles (`textarea`, facultatif, 2000 chars, helper "Laissez vide s'il n'y a aucune réserve.").

**Facture (preview only).** Read-only recap of the lines from the active quote and the deposit/balance selector (radio "Facture d'acompte" / "Facture de solde"). Only "Aperçu".

### B3. Preview then issue (D-02)

Form actions row (`display:flex; gap:8px; flex-wrap:wrap`): `.pt-btn-ghost` "Aperçu", `.pt-btn-primary` "Émettre le document" (disabled until a preview of the current form values has been generated; editing any field invalidates the preview and re-disables "Émettre"). Helper in `.pt-helper`: "Vérifiez l'aperçu. Une fois émis, le document ne peut plus être modifié, seulement remplacé."

Preview region `.pt-doc-preview` below: `<iframe title="Aperçu du document" >` from a blob URL of the base64 PDF, width 100%, height 720px (desktop) / 480px (<640px), border 1px `--pt-border-strong`, background `--bg-3`; above it a banner line (`.pt-warning`, 14px): "Aperçu non conservé. Ce fichier n'est pas celui qui sera émis." (the bytes differ on every render). Blob URL revoked on unmount/new preview. While rendering: button label "Génération de l'aperçu…" and `disabled`; `aria-live="polite"` status. Fallback link "Ouvrir l'aperçu dans un nouvel onglet" (`.pt-btn-text`) for browsers that do not render PDFs in iframes.

**Émettre confirmation (irreversible, not destructive).** Click on "Émettre le document" opens an inline confirm panel in place of the actions row (`role="group"`, `aria-labelledby`): title "Émettre {type} ?" body "Le document sera figé, visible par le client dans son espace, et un e-mail lui sera envoyé." (replacement: "Il remplacera la version {n}, qui restera consultable.") Buttons: `.pt-btn-primary` "Confirmer l'émission", `.pt-btn-text` "Annuler". Focus moves to the confirm title; Escape cancels. The "Confirmer" button is disabled and shows "Émission en cours…" during the action (double-click safe: `documentId` is generated client-side per form open).

**Result states** (`aria-live="polite"` region under the actions):
- Success: `.pt-success` "Document émis. Le client a été notifié par e-mail." The form closes, the issued list refreshes (`router.refresh()`).
- Already issued (idempotent double submit): `.pt-success` "Ce document est déjà émis."
- Mail failed but document issued: `.pt-warning` "Document émis. L'e-mail n'a pas pu partir immédiatement, il sera renvoyé automatiquement."
- Validation error: `.pt-error` per field plus summary "Corrigez les champs indiqués puis relancez l'aperçu."
- Guard errors: "Ce document ne peut pas être émis à l'étape actuelle." / "Émettez d'abord le devis." / "Un document signé ne peut pas être remplacé. Révoquez d'abord la signature depuis le journal des faits." (Pitfall 7 recommendation.)
- Generic failure: `.pt-error` "Le document n'a pas pu être émis. Rien n'a été envoyé au client. Réessayez ; si l'erreur persiste, contactez le support technique."

### B4. Issued documents list (D-16)

`.pt-table` "Documents émis" (caption `pt-sr-only`), newest first, grouped by type like Surface A, replaced rows en retrait (same `.pt-doc-replaced` look). Columns: Document (type + "Version {n}"), Émis le, Statut (same badge), Modèle (`v1`, mono 14px), Empreinte SHA-256 (first 12 hex chars in mono + `title`/button "Voir l'empreinte" which reveals the full 64 chars in the detail), Actions: `.pt-btn-text` "Télécharger" (admin gets the same stored bytes) and `.pt-btn-text` "Voir les données". Expand/collapse via `<details>`-style disclosure (`button aria-expanded`, `aria-controls`) rendering a row-spanning detail region.

Empty: `.pt-helper` "Aucun document émis pour ce projet."

Mobile: stacked-card table mode, same as Surface A.

### B5. Read-only snapshot panel

`.pt-doc-snapshot` (`--bg-3`, 1px `--line`, 8px radius, 16px padding), opened by "Voir les données":
- Header: "Données figées à l'émission" (16px/500) + meta (14px `--ink-dim`): "Modèle v1 · émis le {date} · {size}".
- Full SHA-256 in mono, `word-break: break-all`, with `.pt-btn-text` "Copier l'empreinte" (feedback: label becomes "Copié" for 2 s, `aria-live`).
- Key/value definition list (`dl`) of the snapshot: vendeur, client, projet, lignes (small table), totaux, mentions de TVA, dates. Values 16px/400, keys 14px `--ink-dim`. A collapsed `<details>` "Données brutes (JSON)" shows the pretty-printed JSON in mono 14px, `max-height: 320px; overflow:auto`.
- No edit control anywhere. Notice (14px `--ink-dim`): "Lecture seule. Pour corriger, émettez une nouvelle version."
- Optional action (RESEARCH Pattern 5): `.pt-btn-ghost` "Vérifier l'empreinte" re-downloads the stored object and re-hashes. Result `.pt-success` "L'empreinte correspond au fichier stocké." / `.pt-error` "L'empreinte ne correspond pas au fichier stocké. Ne diffusez pas ce document et prévenez le support technique."

## Surface C — PDF layout (5 templates)

Print contract, independent of the dark UI. Page A4 portrait (595.28 x 841.89 pt), white paper, text near-black. Rendered by `@react-pdf/renderer` from a frozen snapshot; templates `quote`, `contract`, `spec`, `acceptance`, `invoice`, each in `templates/<type>/v1`. All colors are hex literals in `pdf/primitives.tsx` (PDF is outside CSS variables).

### C1. Page grid and spacing (points, multiples of 4)

| Item | Value |
|------|-------|
| Margins | top 48, right 48, bottom 64 (room for footer), left 48 |
| Content width | 499 pt |
| Block gap | 24 |
| Paragraph gap | 8 |
| Table cell padding | 8 vertical, 8 horizontal |
| Header band height | 64 |
| Footer | fixed, bottom 24, left/right 48 |

### C2. Typography (Manrope only, 2 weights: 400 and 700)

| Role | Size | Weight | Line height |
|------|------|--------|-------------|
| Body, table cells, clauses | 10 pt | 400 | 1.5 |
| Label, meta, footer, column headers, fine print | 8 pt | 400 (headers 700) | 1.5 |
| Section heading (clause title, "Désignation" block titles) | 12 pt | 700 | 1.2 |
| Document title ("Devis", "Facture", "Contrat de prestation"...) | 24 pt | 700 | 1.2 |

Four sizes, two weights. No italics (not embedded). Amounts right-aligned, same size as body. No hyphenation (`registerHyphenationCallback((w) => [w])`), so long words wrap whole.

### C3. Colors (print)

| Role | Hex | Usage |
|------|-----|-------|
| Paper | #FFFFFF | Background |
| Ink | #111111 | Body text, titles, amounts (about 90%) |
| Muted | #5A5A5A | Labels, footer, meta (contrast on white 7:1) |
| Rule | #D4D4D4 | 0.75 pt table lines, header rule |
| Band | #F4F4F2 | Table header fill, totals block fill, acceptance zone |
| Accent | none | No brand acid green on paper (illegible on white, wastes ink). Sobriety. Only exception: the PROFORMA/APERÇU stamp text on invoice previews uses Ink bold with a 1 pt Ink border. |

### C4. Common structure (all 5 documents)

1. **Header band** (top): left, seller name "Sèvalys" in 12 pt bold plus legal form line in 8 pt Muted; right, document type title (24 pt bold) and under it reference ("Réf. {reference}", 8 pt) and "Émis le {date}" (8 pt). A 0.75 pt Rule line closes the band.
2. **Parties** (two columns, gap 24): "Vendeur" and "Client" blocks. Each: 8 pt Muted label, then name/denomination (10 pt bold), address, SIRET (vendeur) / SIREN (client), TVA intracom when the client has one, signataire (contrat, PV). Seller block carries the legal identity from `SELLER_V1`: nom, forme juridique (mention "EI" before the name when applicable), SIRET, adresse, RM/RCS ou dispense, plus "TVA non applicable, art. 293 B du CGI".
3. **Document body** (type-specific, below).
4. **Footer (fixed, every page, 8 pt Muted):** left "Sèvalys · SIRET {siret} · {reference}"; center/right "Page {n} / {total}" via `render={({pageNumber,totalPages}) => ...}`. Invoice and quote footers also carry "Modèle {template_version}" at far right (e.g. `v1`) for traceability.
5. Content never splits a table row across pages (`wrap={false}` on rows); section headings use `minPresenceAhead` so a heading is not orphaned at the bottom of a page.

### C5. Per-type body

**Devis (`quote`).** Title "Devis". Meta grid (2 columns, 8 pt labels): Date du devis, Valable jusqu'au (date + "({n} jours)"), Délai de réalisation, Projet. Table: columns Désignation (flex), Qté (48), Prix unitaire HT (96), Total HT (96); header row on Band fill with 8 pt bold labels; body rows 10 pt separated by Rule lines. Totals block right-aligned (width 220) on Band fill: Total HT, "TVA non applicable, art. 293 B du CGI" (8 pt), Total TTC (= HT, 10 pt bold), then Acompte à la commande ({p} %) and Solde à la livraison. Then "Conditions" (12 pt heading): conditions de règlement, pénalités de retard, indemnité forfaitaire de 40 € pour frais de recouvrement, escompte "néant" (shared `LATE_PAYMENT_TEXT`, same wording as invoice). Closing zone "Bon pour accord" (Band fill, 96 high, two columns "Date et signature du client" and "Mention manuscrite « Bon pour accord »") present as a static box; electronic acceptance arrives in phase 14.

**Contrat (`contract`).** Title "Contrat de prestation de services". Fixed clause text from the versioned template, numbered articles: article heading "Article {n} — {titre}" (12 pt bold), clause body 10 pt justified left-aligned (ragged right, no justify to avoid rivers). Order: Parties, Objet (offre du projet), Prix et modalités de paiement (montants repris du devis actif, acompte, solde, franchise 293 B), Délais, Livrables et recette, Propriété intellectuelle, Responsabilité, Confidentialité, Résiliation, Droit applicable. Signature zone at the end (two columns, Band fill, "Pour Sèvalys" / "Pour le client", name + role of signataire, "Date et signature"), kept together on one page. Placeholder note for phase 14 consent clause: none in v1.

**Cahier des charges (`spec`).** Title "Cahier des charges". Meta: projet, date, version. Six sections with 12 pt headings in the fixed order: Contexte et objectif, Périmètre, Livrables, Hors périmètre, Planning, Critères d'acceptation. Admin text is split on blank lines into paragraphs; lines starting with "- " render as bulleted items (indent 16, "•" glyph is in Manrope Latin; verify in spike harness). Acceptance criteria render as a numbered list ("1.", "2." ...) because the PV repeats them literally. No price on this document.

**PV de recette (`acceptance`).** Title "Procès-verbal de recette". Meta: projet, date de livraison, référence du cahier des charges émis (reference + version). Section "Critères d'acceptation" repeats the spec criteria verbatim as a table with columns N° (32), Critère (flex), Conforme (64, an empty 10x10 pt square drawn with a 0.75 pt Ink border, to be ticked on paper or by phase-14 flow). Section "Réserves" shows the admin text, or the line "Aucune réserve." when empty. Closing "Acceptation" zone (Band fill, 96 high): "Le client déclare accepter la livraison" with Date et signature. No price on this document.

**Facture (`invoice`).** Title "Facture". Phase 13: provisional only. Number line reads "Numéro : PROFORMA (aperçu, sans valeur légale)" and a diagonal-free stamp box top-right "APERÇU" (Ink 10 pt bold, 1 pt border, padding 4 x 8) on every page. Meta: Date d'émission, Date de la prestation, Date d'échéance, Nature de l'opération "Prestation de services", Référence du devis, N° de commande if provided. Parties as C4 with client SIREN, and a "Adresse de livraison" line only when it differs from billing. Table as in the quote. Totals: Total HT, "TVA non applicable, art. 293 B du CGI", Total TTC = HT, acompte déjà réglé when relevant, Net à payer (10 pt bold). Block "Règlement": conditions et délai, IBAN/BIC (from `SELLER_V1`), escompte "Escompte pour paiement anticipé : néant", taux des pénalités de retard, "Indemnité forfaitaire pour frais de recouvrement : 40 €". All mandatory strings are plain text (no images) so `unpdf` can extract them (DOC-04).

### C6. Money and text rules for the PDF

- `formatEuros(cents)`: `1 234,50 €` with U+00A0, 2 decimals always, negative not used.
- Percent: `30 %` with U+00A0. Dates `12 octobre 2026`.
- All mandatory mentions are text on the page, never in images, never below 8 pt, never only in the footer except SIRET repetition.
- Metadata: PDF `Title` = "{Type} {reference}", `Author` = seller name, `Language` fr-FR where supported.
- The issue date, reference, totals and seller identity come from the snapshot only (no `new Date()` in templates).

## Copywriting Contract

| Element | Copy |

## Accessibility and Interaction Notes

- Every table has a `caption.pt-sr-only`, `th scope="col"`; status is text, not color alone.
- Focus order on the admin form: fields, "Aperçu", "Émettre". After preview success, focus stays on "Aperçu"; after "Émettre" click, focus moves to the confirm title; after success, focus moves to the success message (`tabIndex={-1}`).
- All async results announced through `aria-live="polite"` regions. Disabled buttons that are blocked by a prerequisite expose the reason through `aria-describedby`.
- Minimum 44px targets; 4.5:1 text contrast (all tokens already verified in phase 10 UI-SPEC; `--ink-dim` on `--bg-2` is used only for 14px meta, accepted precedent).
- iframe preview has `title`; the "Ouvrir dans un nouvel onglet" fallback is always present.
