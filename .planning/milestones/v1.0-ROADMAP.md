# Milestone v1.0: Visual Redesign (Selenium Phase 02)

**Status:** ✅ SHIPPED 2026-05-18
**Phases:** 1-4
**Total Plans:** 21

## Overview

Complete visual redesign replacing the freelance-era portfolio with the Selenium Phase 02 agency brand. Four phases delivered a global design system, a full landing page rebuild, a full services page rebuild, and a final retheme pass covering the demo and legal pages with integration QA.

The site targets local SMB owners (patrons de PME) in Tours, France. Core value: visitor understands what we do, trusts us, and knows how to contact us — in under 60 seconds.

## Milestone Summary

**Key Decisions:**

| Decision | Rationale | Outcome |
|----------|-----------|---------|
| Rebuild pages (not patch) | Mockup is React component-based, fundamentally different structure | ✓ Good — clean result, no regression |
| Keep LanguageContext | Already handles fr/en/th, mockup translations slot in as new keys | ✓ Good — zero breaking changes |
| CSS vars for design tokens | Mockup uses :root CSS vars — matches Next.js globals.css approach | ✓ Good — consistent across all pages |
| Dynamic import for 3D canvas | Three.js / canvas not SSR-safe | ✓ Good — ClientProviders pattern reused in Phase 3 |
| ClientProviders pattern | ssr:false is forbidden in Next.js Server Components (Turbopack) | ✓ Good — adopted for Methodology too |
| Absolute hrefs in nav | Relative hrefs fail when navigating from /services | ✓ Good — cross-page navigation works |
| Baseline commit 5f36fa0 for QA-04 | Pre-Phase-1 planning bootstrap, before any code changes | ✓ Good — clean feuillette integrity check |

**Issues Resolved:**

- StarkDisplay Iron Man component and all freelance-era components removed cleanly
- Dead translation namespaces (hero, about, projects, contact-legacy, footer-legacy, phoneAgent) removed
